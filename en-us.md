# noodUI

[zh-cn](https://github.com/noodultra/noodUI/blob/main/README.md)

### About:
nooUI is a minimalist web UI built with HTML, CSS and JavaScript.
It features card hover effects and gradient links, ideal for personal homepages. It is not recommended for other use cases.  
View[Demo](https://noodui.nood.icu)

### Code
- Languages: HTML CSS JavaScript
- Indentation style: 4 spaces
- Used[VSCode](https://code.visualstudio.com)Coded
