### 简介:
nooUI是一个为简介而生的网页UI 由HTML CSS JavaScript 编写的  
主要实现了卡片悬浮效果 超链接渐变色这些 适用于个人主页 如果干别的 确实不建议  
查看[演示站](https://noodui.nood.icu)

### 代码
- 使用语言: HTML CSS JavaScript
- 缩进风格: 4格缩进
- 使用[VSCode](https://code.visualstudio.com)编写
